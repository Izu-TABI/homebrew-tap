# Izu-TABI の Homebrew tap

[Izu-TABI](https://github.com/Izu-TABI) のアプリを Homebrew で入れるための tap です。

| アプリ | 入れ方 |
|---|---|
| [SideWindow](https://github.com/Izu-TABI/SideWindow)（参照したいウィンドウを、いつも手前に） | `brew install --cask izu-tabi/tap/sidewindow` |
| [TmpSquare](https://github.com/Izu-TABI/TmpSquare)（振れば出てくる、ファイルの一時置き場） | `brew install --cask izu-tabi/tap/tmpsquare` |

アップデートは `brew upgrade --cask <アプリ名>`（例: `brew upgrade --cask sidewindow`）でできます。

Apple の公証を受けていないため、初回だけ macOS に止められます。「システム設定」→「プライバシーとセキュリティ」を開き、そのアプリの「このまま開く」を押してください。

## Homebrew tap for Izu-TABI’s apps

| App | Install |
|---|---|
| [SideWindow](https://github.com/Izu-TABI/SideWindow) (keep the window you’re referring to always on top) | `brew install --cask izu-tabi/tap/sidewindow` |
| [TmpSquare](https://github.com/Izu-TABI/TmpSquare) (shake to open a temporary spot for your files) | `brew install --cask izu-tabi/tap/tmpsquare` |

Update with `brew upgrade --cask <app>` (e.g. `brew upgrade --cask sidewindow`).

The apps aren’t notarized by Apple, so macOS blocks them on first launch. Open System Settings → Privacy & Security and click Open Anyway.
